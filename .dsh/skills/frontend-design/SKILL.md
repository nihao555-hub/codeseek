# 前端设计

先选一个明确的美学方向（编辑印刷、港口工业、窑口手作、Brutalist、杂志网格等），再写组件。不要从「通用 SaaS 卡片」开始。

## 禁止的默认套路

- 紫/蓝渐变底 + 白卡片 + Inter / Roboto / Arial 全家桶
- 每个区块都同样圆角、同样阴影、同样 24px 标题
- 无意义的 fade-in 瀑布、装饰性 Lottie、假 3D
- 用 emoji 当图标系统

港窑独立站已经选定：**Harbor Navy `#16324f` + Kiln Ember `#c45c26` + 金点缀**，衬线标题 Fraunces、正文 IBM Plex Sans。改 `store/` 时延续这套，不要换肤成 Tailwind 默认。

## 要做的

1. **字体即设计**：标题与正文对比拉开。字号阶梯少而狠。
2. **色彩少而偏**：1 个主色、1 个强调、1 个纸色。大面积留纸色，强调色只打点。
3. **空间**：用网格和裁切，而不是到处 padding: 16。
4. **动效**：只解释状态变化（抽屉、筛选、加入购物车）。尊重 `prefers-reduced-motion`。
5. **材质**：渐变、纸纹、焊缝、釉面可以暗示产品，不要假照片堆砌。
6. **文案进入构图**：标题可以断行、可以短句，不要 Lorem。

## 交付

- 说明选了哪条美学方向、避开了什么
- 关键 token（色、字、间距）写进 CSS 变量
- 移动端先保证导航与结算可完成
