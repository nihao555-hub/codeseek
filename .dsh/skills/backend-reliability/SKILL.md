# 后端可靠

## 本店现实

- 订单与询盘在**进程内存**。重启即丢。文档里写清楚，不要假装已持久化。
- 要持久化再用 JSON 文件或 SQLite；不要先上云数据库。
- `createHarborServer()` 每实例一份 `Map`，测试互不污染。

## 规则

1. 所有输入校验在业务函数里（`quoteItems`），handler 只做 HTTP 翻译。
2. 不要吞异常。顶层 try 返回 500 `{ error: 'server' }`，信息可记 stderr，不要把堆栈给买家。
3. 数量必须正整数。库存不足 409，不静默改 qty。
4. 监听 `127.0.0.1`。演示不暴露 0.0.0.0，除非用户明确要求。
5. 开发态没有 `client/dist` 时不要假装首页可用，返回 503 `dev_mode`。
6. 工具代理 / 上游模型那套重试不要套到下单：下单必须一次一单，避免重复订金。

## 日志

启动打一行 `[harbor-kiln] http://127.0.0.1:8788`。不要把邮箱、token 打进日志。
