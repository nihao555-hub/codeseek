# Meta 广告运营

通过 DeepSeek Harness 的 MCP 客户端连接官方 Ads MCP：`https://mcp.facebook.com/ads`。
模型可见工具名形如 `mcp__meta-ads__*`。需要环境变量 `META_ACCESS_TOKEN`（Graph API 用户令牌，权限至少 `ads_read`；写入还要 `ads_management`）。

## 启动检查

1. 若 MCP 工具不在目录里：说明未设置 `META_ACCESS_TOKEN`，给出获取步骤（Graph API Explorer 或商务管理平台系统用户），然后停手。
2. 先列广告账户，确认操作对象，再动任何花费相关字段。
3. 读当前活动/广告组/广告/预算/状态/近 7 天 insights，再给建议。

## 安全规则

- 新建活动、广告组、广告默认 **PAUSED**。未获明确「上线/开启」指示，不要把状态改成 ACTIVE。
- 改日预算、出价、受众、投放国家前，用一句话复述变更与预估花费影响，等确认。
- 不删除历史素材或活动，除非用户明确要求；优先暂停。
- 不把访问令牌、像素 ID 以外的密钥、客户名单写进回复。

## 日常节奏

1. **诊断**：花费、CTR、CPC/CPM、CPA、频次、学习期、拒审。用账户数据说话。
2. **结构**：一句话目标 → 活动预算类型 → 广告组受众/版位 → 素材与文案 → 像素/转化事件。
3. **素材**：主旨、钩子、前 3 秒、卖点、CTA、落地页一致性；多语言时按市场各写一版。
4. **优化**：一次只改一类变量（受众或素材或出价），方便归因。

## 输出格式

- 账户快照（账户、花费、成效、异常）
- 建议动作（按优先级，标明是否需要写权限）
- 若要执行 MCP 写入：列出将调用的工具与关键参数，执行后回报新 ID 与状态
