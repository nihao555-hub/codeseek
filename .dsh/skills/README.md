# 项目 Skills

放在 `.dsh/skills/<name>/SKILL.md`。名字必须 kebab-case。模型用 `skill` 工具加载。

## 业务

| Skill | 何时用 |
| --- | --- |
| `foreign-trade` | 询盘、报价、跟单、合规 |
| `meta-ads` | Facebook / Instagram 广告 |
| `ecommerce-store` | 本仓库港窑独立站约定 |
